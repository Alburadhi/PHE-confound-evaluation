# Configs

nnU-Net plans and training settings (3d_fullres, epoch-matched to the benchmark), and the software versions used.

| File | Contents |
| --- | --- |
| `nnUNetPlans.json` | The full nnU-Net plan, as generated by its self-configuration from the dataset fingerprint. The `3d_fullres` configuration is the one used. |
| `dataset.json` | Channel and label definitions: one CT channel, labels `background` 0 and `PHE` 1, 115 training cases. |
| `paths.py` | The single place where paths are configured. Shipped results resolve relative to the repository; the CT volumes and the nnU-Net output directory are set here or by environment variable. |

Software versions are pinned in `../requirements.txt`. The settings the paper quotes are tabulated in the top-level `README.md`; nothing in the plan was chosen by hand.
